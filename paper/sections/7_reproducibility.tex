\section*{Reproducibility statement}
Every number in the paper is a macro generated from result files: \texttt{bench/paper\_stats.py} computes \texttt{results/*.json} from the per-part scores (\texttt{bench/runs/fresh\_scores.json}, \texttt{fresh\_section\_control.json}, \texttt{agentsk\_*scores.json}), and \texttt{bench/paper\_numbers.py} writes \texttt{paper/numbers.tex}; \texttt{paper/figures/make\_figures.py} draws the figures. Per-part scores come from \texttt{bench/agentsk\_score.py} and \texttt{bench/score.py --cad}. Model identifiers, serving flags and sampling settings are in \texttt{bench/agentsk\_models.py}; the cohort manifest is \texttt{bench/cadbench/index.json} with the fresh file list, and the agent sample is \texttt{study\_parts} with seed 1. The pipeline arms ran from frozen per-arm code snapshots, which are released; the agent study and all analysis code correspond to the repository tag \texttt{paper-v1}. Every under-determined design decision of the agent study is recorded in a decision ledger released with the code.
