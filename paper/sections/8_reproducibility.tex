\section*{Reproducibility statement}
Every result value in the text and tables is a macro generated from committed result files by \texttt{bench/paper\_numbers.py}, and every figure is drawn by a committed script; configuration constants, cohort dates and the counts of the development example in \cref{fig:detail} come from the protocols, the code and the pipeline's records. The protocols, with their dated amendments and execution logs, the frozen source trees of every arm, the cohort definitions (seeded draws excluding earlier model indices), the scoring and analysis code, and the per-part and per-episode records will be released with the paper. Closed-model episodes require an Anthropic API key; their raw records are included, so the analyses can be re-run without the API.
