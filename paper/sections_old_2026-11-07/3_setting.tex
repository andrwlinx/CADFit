\section{Setting and measurement}
\label{sec:measure}

\paragraph{Task and optimizer.}
Given a watertight triangle mesh, the goal is a CadQuery \citep{cadquery} program whose solid matches it. All geometry is normalized so the target is centred and its largest extent spans $[-1,1]$. CADFit \citep{nehme2026cadfit} slices the mesh into planar sections, fits lines and arcs to each loop, proposes extrusion candidates from a Chamfer-distance sweep over translations and revolve candidates from an axis analysis, and composes candidates greedily with union and cut. Backward pruning and residual refinement follow, and the final composition is written out as one CadQuery program. In the released code, a composition is scored by concatenating the candidates' meshes and alpha-wrapping \citep{portaneri2022alphawrap} the result before computing IoU.

\paragraph{Defects in objective and evaluation.}
While extending CADFit on development parts we found defects that change individual scores (\cref{tab:defects}). Two are in the released pipeline: the alpha-wrapped objective fills concave detail (on one smoke-test part the search believed \objBelieved{} where an exact judge measured \objStrict), and a final re-measure alpha-wraps multi-body results and can replace a good composition with a worse fallback. Others came from our own extensions: a body-wise union that filled internal cavities, self-intersecting lofts that passed kernel validity while cancelling their own volume, and exact-union scoring, under which the scored mesh is never produced by running the composed program. These are development case studies, not fresh-cohort estimates, and \cref{tab:defects} states which arms still carry each defect.

\paragraph{Evaluation protocol.}
The same judge scores every arm and every agent. Mesh IoU compares the method's output mesh with the target: exact volumes from manifold booleans \citep{manifold3d} when the output is a closed, consistently wound volume, otherwise a seeded Monte Carlo estimate with generalized-winding-number inside tests \citep{jacobson2013winding}. \iouc{} applies the same judge to the solid obtained by running the final program in a fresh, sandboxed process (no network; writes confined to its folder). A program that does not build scores 0. OpenCascade validity of the shape and of every solid is recorded; \iouc{} keeps the measured score of a built but invalid solid, and the validity-gated \ioug{} is 0 unless the program builds and is valid. Chamfer distance (CD) is the symmetric mean of unsquared nearest-neighbour distances between 20{,}000 points sampled on each surface (target and output mesh, seed 0) in the normalized frame, averaged over parts with an output, with its denominator stated.

\paragraph{Fresh cohort and statistics.}
CADBench's benchA and benchE families \citep{doris2026cadbench} contain ABC-derived parts, the former selected for operation variety and the latter extrusion-based, both stratified by B-rep face count; we use the hard tier. The fresh cohort is a seeded draw of 30 benchA-hard and 30 benchE-hard parts taken after, and disjoint from, all test, development and smoke sets used earlier. All arms run once per part from one code version. Differences are paired by part; intervals are percentile bootstrap over parts \citep{efron1993bootstrap} (10{,}000 resamples, seed 0) and reflect part sampling, not run-to-run randomness. Search-arm comparisons are exploratory with nominal 95\% intervals. For the agent study, comparisons across the six models use Bonferroni-corrected \bonfLevel\% intervals ($\alpha = 0.05/6$). Win/loss counts use a tie threshold of $10^{-9}$.
