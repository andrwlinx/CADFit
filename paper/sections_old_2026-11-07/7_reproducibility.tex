\section*{Reproducibility statement}
Numbers, tables and figures are generated from result files. \texttt{bench/paper\_stats.py} computes \texttt{results/*.json} from the per-part scores (\texttt{bench/runs/fresh\_scores.json}, \texttt{fresh\_section\_control.json}, \texttt{agentsk\_*scores.json}); \texttt{bench/paper\_numbers.py} writes the macros in \texttt{paper/numbers.tex}, \texttt{bench/paper\_tables.py} the generated tables, and \texttt{paper/figures/make\_figures.py} the figures. Development case values are recorded with their sources in \texttt{results/dev\_facts.json} and \texttt{results/defect\_cases.json}; configuration constants (budgets, thresholds) are set in the scripts that use them. Per-part scores come from \texttt{bench/agentsk\_score.py} and \texttt{bench/score.py --cad}. Model identifiers, serving flags and sampling settings are in \texttt{bench/agentsk\_models.py}; arm flags are in \texttt{bench/run\_parallel\_arms.sh} (\cref{app:arms}); the cohort manifest is \texttt{bench/cadbench/index.json} with the fresh file list, and the agent sample is \texttt{study\_parts} with seed 1. The pipeline arms ran from per-arm code snapshots taken at launch; the analysis and agent code correspond to repository tag \texttt{paper-v1}. Each design decision of the agent study that the task left open is recorded, with its rationale, in the decision ledger \texttt{implement-stage/ASSUMPTIONS.md}.
